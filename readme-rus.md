# FarQoiViewer

[English version](README.md)

Плагин Far Manager 3.x для просмотра изображений QOI в отдельном окне Windows.

Изображения QOI декодируются непосредственно плагином. Кодеки PNG, WIC и GDI+ не используются.

## Возможности

- Нажатие `F3` на файле `.qoi` открывает изображение в просмотрщике.
- Поддержка стандартных QOI-изображений с RGB- и RGBA-пикселями.
- Поддержка QOIMT с независимо кодированными полосами и многопоточным декодированием.
- Чтение файлов и декодирование выполняются в фоновом потоке, поэтому интерфейс остаётся отзывчивым во время загрузки.
- Сохранение пропорций изображения.
- Режимы отображения «по размеру окна» и 1:1.
- Масштабирование и панорамирование.
- Отображение прозрачных RGBA-изображений на шахматном фоне.
- Вывод диагностической информации, если файл не удаётся загрузить.
- Отдельное нативное окно Windows с собственным циклом обработки сообщений.
- Файлы других типов по-прежнему обрабатываются Far Manager.

## Управление

| Клавиша / действие | Результат |
|--------------------|-----------|
| `0` | Вписать изображение в окно |
| `1` | Отобразить в масштабе 100% (1:1) |
| `+` / `-` | Увеличить / уменьшить масштаб |
| Колёсико мыши | Изменить масштаб |
| Клавиши со стрелками | Переместить изображение |
| `Home` | Центрировать изображение |
| `Space` / левая кнопка мыши | Переключить режим вписывания в окно и масштабирования |
| `Esc` | Закрыть просмотрщик |
| `w` | Фон: белый |
| `b` | Фон: чёрный |
| `c` | Фон: шахматка |

## Открытие изображения из командной строки Far

Используй префикс плагина `qoi:` и путь к файлу:

```text
qoi: C:\path\to\image.qoi
qoi: "C:\path with spaces\image.qoi"
```

Также можно выбрать файл `.qoi` в панели Far Manager и нажать `F3`.

## Сборка

### Требования

- Windows
- [MSYS2 UCRT64](https://www.msys2.org/) с MinGW-w64 GCC
- CMake версии 3.20 или новее
- Исходный код Far Manager, содержащий `far/plugin.hpp`

Проект использует C++17 и заголовок SDK `far/plugin.hpp` непосредственно из исходников Far Manager. Копия SDK в репозитории не поставляется.

Клонируй исходники Far Manager:

```bash
git clone --depth 1 https://github.com/FarGroup/FarManager.git
```

В приведённых ниже командах предполагается, что исходники Far Manager находятся в `C:/src/FarManager`. При необходимости измени значение `FAR_SOURCE_DIR`.

### Сборка в MSYS2 UCRT64

Выполни команды в терминале UCRT64 из каталога проекта:

```bash
cmake -S . -B build -G "MSYS Makefiles" \
  -DCMAKE_BUILD_TYPE=Release \
  -DFAR_SOURCE_DIR="C:/src/FarManager"

cmake --build build --clean-first --parallel
```

В результате будет создан файл:

```text
build/FarQoiViewer.dll
```

## Установка

Скопируй `FarQoiViewer.dll` в каталог плагинов Far Manager, например:

```text
%FARHOME%\Plugins\FarQoiViewer\FarQoiViewer.dll
```

Если переменная `%FARHOME%` не определена в системе, используй соответствующий путь внутри каталога установленного Far Manager.

После установки или замены DLL перезапусти Far Manager.

## Примечания

- Это плагин для просмотра изображений, а не плагин архивов или виртуальных панелей.
- `F3` перехватывается только для файлов `.qoi`; остальные типы файлов обрабатывает Far Manager.
- Поддержка QOIMT рассчитана на файлы, созданные совместимым кодировщиком QOIMT с независимо декодируемыми полосами.
- Формат QOI: [phoboslab/qoi](https://github.com/phoboslab/qoi).
